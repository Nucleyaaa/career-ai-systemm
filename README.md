# AI Career Transition Intelligence System

A comprehensive career recommendation platform that uses AI to analyze personality, skills, market trends, and provide personalized career paths with learning roadmaps.

## 🚀 Features

- **Personality Assessment**: Big Five (OCEAN) and Holland Code (RIASEC) analysis
- **Career Matching**: AI-powered career recommendations based on personality and skills
- **Market Intelligence**: Real-time salary data, demand forecasts, and risk analysis
- **Learning Paths**: Customized learning roadmaps with timeline estimates
- **Risk Scoring**: Automation risk and market volatility analysis
- **Interactive Dashboard**: Visualize career matches and progress

## 🛠️ Tech Stack

- **Frontend**: Next.js, React, TailwindCSS, Recharts, Framer Motion
- **Backend**: FastAPI, Python
- **AI/ML**: scikit-learn, XGBoost, Prophet
- **Database**: PostgreSQL
- **Infrastructure**: Docker, Docker Compose
